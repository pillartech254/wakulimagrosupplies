📱 Multi-Device User Sync Super Admin Only
PillarPOS stores all data (users, products, credits) in the browser's local storage — which means each device starts fresh. When staff open the POS on a phone, tablet, or new laptop, they see no products and can't log in properly.

After downloading: go to app.netlify.com → Sites → wakulimaagro → Deploys → drag & drop the downloaded file.

🗑 Database Reset
🚨
SUPER ADMIN — DATABASE RESET CONTROLS
Each button acts independently. A backup is auto-created before every action. All actions are irreversible.
🧾 Sales Transactions

Clears all sales records. Dashboard revenue and analytics reset to zero.

🤝 Credit Balances

Zeroes all customer outstanding credit balances. Accounts stay, only amounts reset.

📦 Products / Inventory

Deletes all products from inventory. Product list becomes empty.

👥 Staff Accounts

Removes all staff/cashier accounts. Your Super Admin account is preserved.

☢️ Full Database Reset — Wipe Everything & Start Fresh

Executes ALL four resets above in one go — transactions, products, credit balances, and staff accounts. Only your Super Admin login is preserved.

A full backup is created automatically first. You can restore from the Backup page if needed.

📋 Transaction Detail
🚫 Revoke Sale
⚠️ This action cannot be undone
Revoking restores stock, reverses any credit balance change, and marks the sale as voided. All admins will be notified.
Cloud tip: If using Supabase, run this migration once in SQL Editor:
ALTER TABLE transactions ADD COLUMN IF NOT EXISTS voided BOOLEAN DEFAULT false;
ALTER TABLE transactions ADD COLUMN IF NOT EXISTS void_reason TEXT;
ALTER TABLE transactions ADD COLUMN IF NOT EXISTS voided_by TEXT;
ALTER TABLE transactions ADD COLUMN IF NOT EXISTS voided_at TIMESTAMPTZ;
🗑️ Delete Credit Sale
⚠️ This will reverse the credit sale
All unpaid credit sale transactions for this customer will be voided and stock will be restored. Payments already received are NOT reversed — only the outstanding balance is cleared. You can then re-sell at the correct amount.
🗑️ Delete Creditor
⚠️ Permanently removes this creditor
The creditor record will be deleted. If they have an outstanding balance, all linked credit sale transactions will also be voided and stock restored first. This cannot be undone.
